# Promo Banner Block

## Overview
Displays promotional messaging within the storefront.

## Configuration
The block reads content from the associated page authoring configuration.

## Behaviour
- Renders promotional content on page load.
- Supports dynamic updates based on authored content.
- Gracefully handles missing content.

## Integration
- Loaded as a standard AEM block.
- Uses the storefront block framework.

## Error Handling
- Missing content results in no banner being rendered.
- Invalid configuration is ignored safely.
